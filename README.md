# ANAM — منصة ذكاء المستجدات 📡

> تلتقط **كل ما هو جديد** في عالم البرمجيات والذكاء الاصطناعي على الإنترنت، تحلله وتصنفه وتشخصه،
> وتحوّله إلى **تقرير عربي عملي**: ما هو؟ مجاله؟ كيف تستخدمه؟ وكيف تستفيد منه في شغلك وحياتك وربحك ووقتك.

- ✅ **مجاني 100%** — GitHub Search API + سجل npm + أي RSS + SQLite محلي. صفر تبعيات خارجية (stdlib فقط).
- ✅ **بدون توقف** — `anam daemon` أو GitHub Actions مجدول كل 6 ساعات.
- ✅ **وضعان كما طلبت** — الوضع العادي (الافتراضي، الضجة فقط) والوضع التام (كل شيء بدون فلترة).
- ✅ **تشخيص بدون حدود** — `anam diagnose` يشخّص أي مستودع/حزمة/رابط/كلمة مفتاحية بلا أي شرط نجوم أو مشاهدات.

## التركيب والتشغيل السريع

```bash
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"   # أو: بدون أي تثبيت، استخدم python3 -m anam.cli
anam scan                    # المسح بالوضع العادي (الافتراضي) + تقرير
anam scan --mode full        # الوضع التام: كل المستجدات بدون فلترة
anam report --mode normal    # إعادة توليد التقرير من الذاكرة المحلية (بدون شبكة)
anam diagnose owner/repo     # تشخيص عميق لمستودع GitHub
anam diagnose npm:nome…      # تشخيص حزمة npm
anam diagnose "ai agents"    # بحث حر ثم تشخيص الأفضل
anam self-improve            # ANAM يقترح كيف يطور نفسه من المستجدات الملتقطة
anam daemon --interval-minutes 360   # تشغيل بلا توقف (كل 6 ساعات)
anam status                  # إحصائيات الذاكرة المحلية
```

### المخرجات
- `reports/anam-report-<التاريخ>.md` — التقرير العربي: ملخص تنفيذي ← أقسام حسب المجال ← كل عنصر بخمسة أجوبة (ما هو / مؤشراته / كيف تستخدمه / أين يفيدك في الشغل والربح والحياة والوقت وSaaS / التصنيف) ← قسم «💡 فرص مرشحة للتنفيذ الآن».
- `reports/anam-report-<التاريخ>.json` — نفس البيانات بصيغة آلية لأي لوحة/أداة أخرى.
- `reports/diagnose-<العنصر>-<التاريخ>.md` — تقرير تشخيص مفصل لأي عنصر.
- `reports/self-improvement-<التاريخ>.md` — خطة تحسين ذاتية مرتبطة بعناصر حقيقية رُصدت.
- `reports/sample-report.md` — نموذج تقرير حقيقي مولّد من بيانات حية (2026-11-13).

## الوضعان (الافتراضي = العادي)

| الوضع | ماذا يفعل | لمن |
|---|---|---|
| **العادي** (`--mode normal`) | يمرّر فقط ما **أحدث ضجة**: صعود ملفت (افتراضيًا ≥ 25 ⭐/يوم، أو مستودع حديث بـ ≥ 500 نجمة، أو حزمة بـ ≥ 50 ألف تحميل أسبوعيًا/مؤشرات تبنٍّ)، ثم يرتب بالأعلى ضجة ويعرض أفضل 50 | القراءة اليومية السريعة |
| **التام** (`--mode full`) | يمسح **كل** المستجدات بدون أي فلترة (حتى 300 عنصر) | البحث العميق والرصد الشامل |

العتبات كلها قابلة للتعديل في `anam_config.json` تحت `filters` — وANAM يتعلم «السرعة» الحقيقية مع تراكم التشغيلات (يقارن أحدث لقطتين في SQLite بدل الاعتماد على عمر المشروع فقط).

## التشغيل بلا توقف (مجاني بالكامل)

**الخيار 1 — GitHub Actions (موصى به):** المستودع يتضمن `.github/workflows/anam-scan.yml` — يعمل كل 6 ساعات تلقائيًا على بنية GitHub المجانية، ويرفع التقارير كـ artifacts. يكفي دفع المستودع إلى GitHub وتفعيل Actions. `GITHUB_TOKEN` يُحقن تلقائيًا (مجاني) — أو أضف `secrets.GITHUB_TOKEN` بصلاحية القراءة لرفع الحدود.

**الخيار 2 — خادمك/جهازك:**
```bash
nohup anam daemon --interval-minutes 360 > anam.log 2>&1 &
```

## مصادر البيانات الحالية
- **GitHub** — مستودعات منشأة/مدفوعة حديثًا (Search API، بدون مفتاح مع حد 10 طلبات/دقيقة، أو بـ `GITHUB_TOKEN` مجاني).
- **npm** — حزم حديثة + تحميلات أسبوعية + عدد المعتمدين عليها (ضمن نتيجة البحث نفسها، بدون مفتاح).
- **RSS/Atom** — أي موجز تضيفه في `rss.feeds` (افتراضيًا Hacker News). ⚠️ هذا المصدر يحتاج شبكة مفتوحة — إن لم يكن متاحًا في بيئتك يفشل بهدوء ويكمل الباقي.

### إضافة مصدر جديد (5 دقائق)
أنشئ `anam/sources/mysource.py` بفئة ترث `Source` وتعيد `list[Item]` (لا ترمِ استثناءً — أعد `[]`)، ثم سجله في `anam/sources/__init__.py`. باقي النظام (تخزين، تحليل، تقارير) يعمل معه تلقائيًا.

## ما الذي يقيسه ولماذا؟
- **سرعة الصعود ⭐/يوم** — بين أحدث لقطتين متتاليتين؛ بدون تاريخ كافٍ يُستخدم العمر كبديل مؤقت.
- **درجة الضجة 0–100** — حداثة + حجم + سرعة + تبنٍّ فعلي.
- **التصنيف المحلي** — ~13 مجالًا (AI، أتمتة، Micro-SaaS، بيانات، تداول، أمن، ويب، أدوات مطور، DevOps، جوال، حياة شخصية، محتوى، عام) بكلمات مفتاحية مرجحة — بدون API مدفوع.
- **خريطة «أين يفيدك؟»** — لكل مجال: فوائد في الشغل والربح والحياة واختصار الوقت وفرص Micro-SaaS.

## حدود صادقة (اقرأها)
- التقارير **تلقائية وإرشادية**: الأرقام دقيقة لحظة الالتقاط، لكن «يستحق التبني» حكم أولي — راجع README والرخصة وتاريخ آخر تحديث قبل الاعتماد (وأمر `diagnose` يعطيك هذا التشخيص جاهزًا).
- ANAM **لا يولّد زيارات أو نقرات وهمية** لأي منصة إعلانية ولا يتحايل على أي كشف — هو رادار معلومات فقط.
- «الضجة» مؤشر وليست إثبات جودة؛ والفرص المقترحة تحتاج دراستك الخاصة قبل الاستثمار بها (خصوصًا المالي: ليست نصيحة استثمارية).
- التشغيل المستمر يخضع لحدود GitHub/npm المجانية؛ مع `GITHUB_TOKEN` تكفي بسهولة للاستخدام الشخصي.
